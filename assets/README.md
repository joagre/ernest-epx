# The pictures

What the examples draw, as PNG, for the READMEs: `mandelbrot.png`, `sierpinski.png` and `raytracer.png` are each program's own output, `build/examples/<name>.ppm` after `make test`, converted with `convert <name>.ppm <name>.png`; `collage.png` is the three side by side, 256 pixels high, for the top of [`README.md`](../README.md). A picture is made again when its program changes what it draws.
