# The pictures

What the examples draw, as PNG, for the READMEs: `mandelbrot.png`, `sierpinski.png`, `raytracer.png`, `clock_face.png` and `whitted.png` are each program's own output, `build/examples/<name>.ppm` after `make test`, converted with ImageMagick's `convert <name>.ppm <name>.png`; `whitted16.png` is `whitted.ern`'s picture with sixteen samples, written by `ern run --load-path build --libs-dir lib examples/build/whitted.erc whitted16.ppm 8 16` and converted the same way; `collage.png` is the five laid out together by hand, Whitted's spheres at sixteen samples among them, 681 by 511 pixels, for the top of [`README.md`](../README.md). A picture is made again when its program changes what it draws.
