# The pictures

What the examples draw, as PNG, for the READMEs: `mandelbrot.png`, `sierpinski.png`, `raytracer.png`, `clock_face.png` and `whitted.png` are each program's own output, `build/examples/<name>.ppm` after `make test`, converted with `convert <name>.ppm <name>.png`; `whitted16.png` is `whitted.ern`'s picture with sixteen samples, written by `whitted whitted16.ppm 8 16` and converted the same way; `collage.png` is the five together, Whitted's spheres at sixteen samples among them, 4096 by 3072 pixels, for the top of [`README.md`](../README.md). A picture is made again when its program changes what it draws.
