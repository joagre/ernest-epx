# Changes

Each release's note, newest first, from the release after 0.2.0 on; the release step writes a release's section before its tag and copies it to the release on GitHub, so that the note is written once (`docs/release.md`). A section says what the release is, what a program or an operator of the previous release changes, and each change on one line naming the design's section where it is read; it restates nothing, and its date stands in its heading alone.
