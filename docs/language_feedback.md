# Language feedback

What writing Ernest felt against the principles, a line each, as `CLAUDE.md` says: a queue, each line carried to Ernest, and the file goes when it is empty.

- **A vector cannot be multiplied by a number with `*`.** A member named by an operator has the type `(T, T) -> R` (report §4.8), so `fn Vector.*(vector : Vector, factor : Float)` is refused, and scaling is the function `scaled` in `examples/raytracer.ern`, `examples/whitted.ern` and `examples/boids.ern`. Vector arithmetic then mixes operators and a call, `ray.origin + scaled(ray.direction, distance)`, and a `Color` is scaled as `* gray(level)`. The raytracer's proposal wrote `*` by a number, which is what a reader predicted. Principle 1. Ask: §4.8 admits `T.*` of a `T` and a number, or states why scaling is a function.

  Carried 2026-10-20 as Ernest's 133. 0.10.0 leaves §4.8 as it was, and states no verdict.
- **`Float.sqrt` and `Float.pow` answer `Optional` where the argument cannot fail them.** The square root of a sum of squares, a vector's length, and a base not below zero to a power, a highlight's level, each write a `None` arm that cannot run, a `fault` naming why: `length` and the glint in `examples/raytracer.ern`, `length` in `examples/boids.ern`, `squareRoot` and `power` in `examples/whitted.ern`. The compiler cannot see that the arm cannot run, and the reader meets a case the program cannot reach in `length`, which every vector program writes first. Principle 3. Ask: a root and a power written without an arm that cannot run, or the report's reason that every caller writes it.

  Carried 2026-10-20 as Ernest's 134. 0.10.0 leaves E.9 as it was, and states no verdict.
- **Two modules of one library cannot share a private function.** `Epx.Gc` and `Epx.Window` check a width and a color by the rules and causes `Epx` checks them by, and since a declaration is either private to its module or exported to every program (report §4.2), the private functions are written again in each, `src/epx/gc.ern` and `src/epx/window.ern`, rather than exported from `Epx` as functions no caller should see. The same split puts the tests of `Epx`'s drawing functions in `Epx.Gc`, the one module that can make a context, since `Epx` cannot name a module that names it (§4.1). Principle 2. Ask: a declaration the modules of one library share and no other program reaches, or the report's reason that a library is no unit of privacy.

  Carried 2026-10-20 as Ernest's 135. 0.10.0 leaves §4.1 and §4.2 as they were, and states no verdict.
