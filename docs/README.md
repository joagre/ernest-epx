# The documents

What each document of this repository is. [`README.md`](../README.md) says what the library is and how it is built, tested and used.

- **[`design.md`](design.md)**: how the library is arranged, the normative document of this repository, and the glossary of its names.
- **[`plan.md`](plan.md)**: where the library stands and what comes next.
- **[`log.md`](log.md)**: the dated rationale, never normative.
- **[`release.md`](release.md)**: what a release runs to be ready.
- **`proposals/`**: what is designed, a directory for each proposal while one is open; none is open.
- **`language_feedback.md`**, under `docs/` from its first line and absent while it is empty: what writing Ernest felt against the principles, a queue carried to Ernest by its issue tracker, or, for an application built in Ernest's clean room, by a message to Ernest's session.
- **[`CLAUDE.md`](../CLAUDE.md)**: the working rules.
- **[`epx_bugs.md`](epx_bugs.md)**: the defects found in epx that its pinned commit has not fixed, each a report for its tracker.
- **[`THIRD_PARTY_LICENSES`](../THIRD_PARTY_LICENSES)**: epx's license and tree_db's standing, which the release archive carries with their compiled code.
- **[`ACKNOWLEDGMENTS.md`](../ACKNOWLEDGMENTS.md)**: the people this library stands on, by name alone.
